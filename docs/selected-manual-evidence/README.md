# Selected-manual browser captures

These PNGs are LCD-only screenshots generated by the calculator app; they are not scans or crops of the printed guide. The older E-21/E-30/E-33 captures came from the pinned three-project browser matrix (99/99 at that run). The E-4/E-7/E-8/E-17/E-37 captures below were refreshed from an isolated production Vite build at 390x844 in Chromium on port 5200; the selected viewport run17 passed 5/5. Run18 added isolated production checks on Chromium, Pixel 7 mobile and iPad Mini tablet using a separate Vite output directory and Playwright output directory under `%TEMP%`; the listed run17 screenshot files were not replaced. Run18 passed the E-4 viewport, E-8 height/recovery, E-17 bounds/prompt and ordinary short-result AC cases in all three profiles, plus the three E-17 numerical examples in Chromium. The E-36 CONST prompt is from an earlier isolated production capture. Browser images and measurements document the local app and do not establish physical-calculator parity.

Run11 E-8 geometry is also logged by the browser test: accepted 220.484 px; refused candidate 252.391 px; panel 125.734 px; screen cap 251.469 px. Run18 cross-profile values are listed in the E-8 row above. Formula height admission is reconstructed from the manual's 31-dot screen and browser DOM glyph metrics, not hardware raster evidence. E-4 result scrolling advances by one displayed-character width per arrow press in this implementation; the guide does not specify the physical increment.

Run15 also checks menu and history status indicators through real key buttons: SETUP page 1/2 uses down/up respectively, and the E-12 3+3, 2+2, 1+1 history walk updates replay arrows at each position. Replay markers are suppressed while a menu occupies the status row.

Run18 ordinary AC geometry measured a 2.94 px Natural content excess (4 px in integer `scrollHeight` reporting) on `1+1`, below one 7-dot glyph cell at the measured panel scale, so AC cleared instead of recalling that expression. The restored-input state is transient and is committed to editing by arrow navigation; SHIFT/ALPHA remain pending modifiers, and the first mapped entry key clears the recalled expression before starting the next calculation. The one-AC E-17 sequences and E-37 `100`, `SHIFT 8` prompt pass without adding an extra AC. These measurements validate the app's DOM policy only; the guide does not publish exact glyph raster dimensions.
